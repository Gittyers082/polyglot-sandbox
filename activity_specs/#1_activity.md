# Activity 1: Digit Analysis Program

## 🎯 Objective

Create a program that solves the logic problem detailed below in your chosen programming language.

---

## 📋 Requirements

You must use standard coding conventions for your chosen language (e.g., proper variable naming, standard indentation, and idiomatic language features).

### 1. Input

- A single positive integer (e.g., `3487`).

### 2. Processing

- **Sum:** Find the sum of all digits in the original number.
- **Reverse:** Reverse that sum using **arithmetic operations only**.
  - ⚠️ _Strict Constraint:_ Do **NOT** convert numbers to strings, arrays, or lists to reverse them.
- **Prime Check:** Determine if the reversed sum is a prime number.
- **Parity Check:** Determine if the reversed sum is even or odd.
- **Filter Count:** Count how many individual digits in the original number are strictly greater than 5 (`> 5`).
- **Implementation:** Use iteration (such as `for` or `while` loops) or recursion to perform the math and structural analysis, depending on what is most appropriate and idiomatic for your chosen language.

### 3. Output

Your program must display the following data clearly:

1. Original number
2. Sum of all digits
3. Reversed sum of all digits
4. Prime status of the reversed sum (Is Prime / Not Prime)
5. Parity status of the reversed sum (Even / Odd)
